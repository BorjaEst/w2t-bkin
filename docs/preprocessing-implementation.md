# Preprocessing Phase Implementation

## Overview

Implemented a preprocessing phase (Phase 2) in the W2T Body Kinematics pipeline to support intermediate data processing steps, such as DLC pose estimation, that can be:

- Manually provided by users (placed in `data/interim/<session_id>/`)
- Automatically generated by the pipeline when enabled in configuration

## Architecture

### Task Framework

Created a generic task-based architecture for preprocessing operations:

**`src/w2t_bkin/tasks/base.py`**

- `TaskStatus` enum: PENDING, SKIP, CACHED, REQUIRED, RUNNING, COMPLETED, FAILED
- `TaskConfig` dataclass: Configuration holder for task execution
- `PipelineTask` ABC: Base class with lifecycle management
  - `check_dependencies()`: Validate prerequisites (config, files, models)
  - `check_output()`: Check if outputs already exist
  - `execute()`: Perform the actual task
  - `run()`: Orchestrate full lifecycle with logging

### DLC Pose Estimation Task

**`src/w2t_bkin/tasks/dlc.py`**

- `DLCPoseTask`: Concrete implementation for DeepLabCut pose estimation
- **Dependency checking**: Validates cameras, video files, and DLC model
- **Output validation**: Checks for existing H5 files in interim/dlc folder
- **Execution**: Calls `dlc.core.run_dlc_inference_batch()` if needed
- **Smart caching**: Skips processing if outputs exist unless `force_rerun=True`

### Configuration

**`src/w2t_bkin/config.py`**

- `DLCPreprocessingConfig`: DLC-specific settings (enabled, model_path, gpu, save_csv)
- `PreprocessingConfig`: Container for all preprocessing tasks (force_rerun, dlc)
- Integrated into root `Config` model with default factory

**`configs/standard.toml`**

```toml
[preprocessing]
force_rerun = false

[preprocessing.dlc]
enabled = false
model_path = "models/iteration-1/BA_W2T_cam0.newOct30-trainset95shuffle1/config.yaml"
save_csv = false
```

### Pipeline Integration

**`src/w2t_bkin/pipeline.py`**

- Updated from 6-phase to 7-phase workflow
- **Phase 0**: Initialization - Load config, create NWBFile
- **Phase 1**: Discovery & Verification - Find files, verify consistency
- **Phase 2**: Preprocessing _(NEW)_ - Generate intermediate artifacts
- **Phase 3**: Ingestion - Process Bpod, Pose, TTL data (renamed from Phase 2)
- **Phase 4**: Synchronization - Align data streams (renamed from Phase 3)
- **Phase 5**: Assembly - Add all objects to NWBFile (renamed from Phase 4)
- **Phase 6**: Finalization - Write NWB, validate, create sidecars (renamed from Phase 5)

**`_phase_2_preprocessing()` implementation:**

1. Creates interim directory structure (`data/interim/<session_id>/`)
2. Builds `TaskConfig` from pipeline config and metadata
3. Instantiates and runs enabled tasks (currently DLC)
4. Handles task lifecycle: dependency check → output check → execution
5. Logs task status (COMPLETED, CACHED, SKIP, FAILED)
6. Raises `IngestError` on task failure

## Usage

### Enable DLC Preprocessing

Edit your config TOML:

```toml
[preprocessing.dlc]
enabled = true
model_path = "models/dlc/config.yaml"
```

### Run Pipeline

```bash
python -m w2t_bkin.cli run configs/standard.toml subject-001 session_20251120 --log-level DEBUG
```

### Manual Interim Files

Place pre-processed files in:

```
data/interim/<session_id>/dlc/
  ├── cam0_<timestamp>DLC_*.h5
  ├── cam1_<timestamp>DLC_*.h5
  └── ...
```

Pipeline will detect and use these files (status: CACHED).

### Force Regeneration

Set in config:

```toml
[preprocessing]
force_rerun = true
```

Or programmatically:

```python
task_config = TaskConfig(force_rerun=True, ...)
```

## Extension Points

### Add New Preprocessing Tasks

1. **Create task class** in `src/w2t_bkin/tasks/`:

   ```python
   from .base import PipelineTask, TaskConfig, TaskStatus

   class MyTask(PipelineTask):
       def check_dependencies(self) -> bool:
           # Validate prerequisites
           return True

       def check_output(self) -> bool:
           # Check if output exists
           return False

       def execute(self) -> None:
           # Perform processing
           pass
   ```

2. **Add config model** in `src/w2t_bkin/config.py`:

   ```python
   class MyTaskConfig(BaseModel, extra="forbid"):
       enabled: bool = Field(default=False)
       # Add task-specific fields

   # Update PreprocessingConfig
   class PreprocessingConfig(BaseModel, extra="forbid"):
       force_rerun: bool = Field(default=False)
       dlc: DLCPreprocessingConfig = Field(default_factory=DLCPreprocessingConfig)
       my_task: MyTaskConfig = Field(default_factory=MyTaskConfig)  # NEW
   ```

3. **Execute in pipeline** in `src/w2t_bkin/pipeline.py`:

   ```python
   def _phase_2_preprocessing(self, context: PipelineContext) -> None:
       # ... existing code ...

       # Execute MyTask if enabled
       if context.config.preprocessing.my_task.enabled:
           my_task = MyTask(task_config)
           status = my_task.run()
           # Handle status...
   ```

4. **Add to config file**:
   ```toml
   [preprocessing.my_task]
   enabled = false
   # Add task-specific settings
   ```

## Implementation Notes

- Task execution is atomic: either all succeed or fail
- Tasks log at appropriate levels (INFO, DEBUG, ERROR)
- Failed tasks raise `IngestError` with context and hints
- Force rerun applies to all preprocessing tasks
- Interim directory structure: `interim/<session_id>/<task_name>/`
- Output file naming follows DLC conventions: `<camera>_<timestamp>DLC_*.h5`

installation

pip

you need to install manually ndx-structured-behavior to use this package (till the authors publish it in PiPy). You can install it via pip:

```bash
git clone https://github.com/rly/ndx-structured-behavior.git
pip install -U ./ndx-structured-behavior
```

Once the dependency is installed, you can install w2t_bkin via pip:

```bash
pip install w2t_bkin
```
